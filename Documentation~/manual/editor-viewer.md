# Editor Viewer

Open `Window > HerdKV > Viewer` in the Unity Editor.

The viewer can:

- open a HerdKV database folder
- discover child database folders when you open the parent `HerdKV` container folder
- list live keys
- search keys
- show selected entry metadata such as segment, offset, and value size
- preview UTF-8 or hex values
- export selected values
- delete keys
- compact a database
- show corruption warnings from inspection
